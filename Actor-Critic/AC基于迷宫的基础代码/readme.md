🌀 Actor-Critic Maze (稳定版)

—— 动态折扣因子 γ + 熵衰减 + BFS 势函数 + Critic 数值防爆

本项目实现了一个 稳定收敛的 Actor-Critic 强化学习迷宫环境。
相比经典 Actor-Critic，本实现加入了：

✔ 动态折扣因子 γ 衰减

✔ 动态熵系数（减少后期探索）

✔ BFS 势函数 Reward Shaping

✔ Critic TD-Target 数值裁剪（关键稳定性技巧）

✔ 来回移动惩罚 / 重复访问惩罚

✔ 最终形成「平稳上升的训练曲线」

最终的训练结果（test4）如下：

曲线呈现稳定上升趋势，后期回报接近理论最优（≈5.8），无明显“崩溃”区段。

📌 1. 项目亮点（核心特性）
🔹 1. 动态折扣因子 γ

训练中逐渐从 长远规划（高 γ）→ 更关注当前（低 γ）：

if episode % 20 == 0:
    self.gamma = max(0.85, self.gamma * 0.999)


让前期易探索，后期易收敛，减少回报方差。

🔹 2. 动态熵系数：逐渐减少探索

前期需要探索，后期完全停止随机性：

if episode > 350:
    self.entropy_coef = 0.0


让训练曲线更“稳”，避免后期乱跳。

🔹 3. BFS 势函数 Reward Shaping

训练前用 BFS 计算每个格子到终点的距离。

奖励含义：

向终点靠近 → 加分

远离终点 → 扣分

查询简单、梯度稳定、无需复杂潜在函数

🔹 4. Critic 数值防爆（关键！）

为防止值函数 V(s) 爆炸，强制限制 TD target：

td_target = torch.clamp(td_target, -5, 5)


这是 test4 比 test5 收敛更稳的主要原因。

🔹 5. 重复访问 / 来回移动惩罚

避免 agent 在局部“抖腿”或循环原地：

if rc == prev_rc:
    reward -= 0.2
if visit_count[rc] > 3:
    reward -= 0.05

📌 2. 环境说明（Maze）

4×4 网格迷宫

红色方块：智能体

黑色：障碍（-1 reward）

黄色：终点（+5 reward）

白色：普通地面（-0.01 每步）

BFS 势函数引导靠近终点

📌 3. Reward 设计（稳定回报的核心）

完整 reward 结构：

奖励项	数值	作用
step_penalty	-0.01	避免无限游走
BFS 势函数奖励	0.3 × tanh(d_prev - d_now)	激励靠近终点（有界）
距离动态步惩罚	-0.005 × dist/(H+W)	越靠近终点惩罚越少
来回跳动惩罚	-0.2	避免原地抖动
重复访问惩罚	-0.05	防止局部回路
终点奖励	+5	收敛目标

这种「有界化 + 方向性」的 reward 使得策略更新更平稳。

📌 4. 训练结果分析（test4）

训练结果呈现以下特点：

前 0–200：探索期，回报在 -2～0 乱跳

200–350：开始学到正确路径，回报快速上升

350 以后：熵衰减到 0，曲线稳定

最终稳定在 3.5~4.5 左右

偶尔最高超过 5（接近理论最优 ≈5.8）

test4 相比 test5 必胜点：
无大幅崩盘，无大幅震荡。

如果你把两图放在一起非常明显：

test5 有一次严重“掉回 0 区段”的崩溃（约第 480 集）

test4 完全没有这种灾难性更新

说明 td_target 裁剪 + 有界 reward 是成功的稳定性设计。
